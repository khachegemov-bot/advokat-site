# Сайт адвоката — одностраничный лендинг

Сайт адвоката по уголовным делам для реального клиента. Задача — чтобы человек, у которого случилась беда, нашёл защитника, понял, чем тот может помочь, и записался на консультацию.

## Инженерные решения

Каждое принято ради измеримого результата, а не ради моды.

### Форма записи работает без серверной части

Форма из трёх шагов собирает ответы — стадия дела, срочность, описание, контакты — складывает их в текст сообщения и открывает WhatsApp адвоката с уже готовым письмом.

Почему так: сайту не нужны ни база данных, ни почтовый сервис, ни обработка персональных данных на сервере. Заявка приходит туда, где адвокат её точно увидит, а сайт остаётся статикой, которую можно положить куда угодно.

### Шрифты развёрнуты локально

Изначально Playfair Display и Inter подключались с Google Fonts. На мобильном интернете это давало плавающую задержку: два сторонних домена, два отдельных TLS-рукопожатия до появления первой буквы.

Шрифты перенесены на свой сервер, разбиты по наборам символов через `unicode-range` — телефон с русской страницей скачивает только кириллицу. Обращений к сторонним доменам при загрузке страницы: **ноль**.

### Шрифт обрезан до одного символа

У Playfair Display средняя перекладина в букве «Э» нарисована волнистой и выбивается из строки. Буква взята из PT Serif, а сам шрифт обрезан инструментом `fontTools` до единственного нужного глифа.

**22 КБ → 1,5 КБ.** Подключён через `unicode-range: U+042D`, поэтому скачивается только ради этой буквы и ни для чего больше.

### Кэширование со сменой версии

Статике выставлен срок хранения в 30 дней — это ускоряет повторные заходы, но делает правки невидимыми для тех, кто уже был на сайте. Поэтому ссылки версионируются: `styles.css?v=3`. Смена версии — смена адреса файла, и браузер гарантированно берёт новый.

### Доступность

- анимации появления отключаются при системной настройке `prefers-reduced-motion`;
- осмысленная разметка: `header`, `nav`, `section`, `article`, `blockquote`, `dl`;
- `aria-label` и `aria-expanded` на интерактивных элементах;
- вся навигация доступна с клавиатуры, фокус виден.

## Устройство

```
index.html     разметка
styles.css     оформление, адаптив, тёмная палитра
app.js         появление блоков при прокрутке, меню, форма записи
fonts.css      описание шрифтов с разбивкой по наборам символов
fonts/         Playfair Display, Inter, обрезанный глиф
portrait.jpg   портрет
```

Анимации появления сделаны на `IntersectionObserver`, прокрутка обрабатывается через `requestAnimationFrame` — чтобы не пересчитывать раскладку на каждое движение колеса.
