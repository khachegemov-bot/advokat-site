# Сайт адвоката Чегемова Яна Эдуардовича

Одностраничный сайт адвоката по уголовным делам. Владикавказ, Алагир.

**Живой сайт:** https://advokat.ossetiawork.ru

## Что это

Статический сайт без серверной части и базы данных. Четыре файла и папка со шрифтами — кладётся на любой хостинг и работает.

Форма записи на консультацию собирает ответы в сообщение и открывает WhatsApp, поэтому бэкенд для неё не нужен.

## Устройство

```
index.html     разметка страницы
styles.css     оформление
app.js         анимации, меню, форма записи
fonts.css      подключение шрифтов
fonts/         Playfair Display и Inter, локальные копии
portrait.jpg   портрет
```

## Разделы страницы

Обложка · манифест · об адвокате · практика по стадиям дела · порядок работы · возможные результаты · запись на консультацию · контакты.

## Решения, принятые при разработке

**Шрифты лежат локально.** Загрузка с Google Fonts заметно замедляла открытие сайта на мобильном интернете: два лишних домена, два отдельных защищённых соединения до появления первой буквы.

**Буква «Э» взята из PT Serif.** В Playfair Display средняя перекладина у неё волнистая и выбивается из строки. Шрифт обрезан до одного глифа — 1,5 КБ вместо 22 КБ.

**Ссылки на стили и скрипт версионированы** (`styles.css?v=3`). Статике выставлен долгий срок кэширования, и без смены версии правки не доходят до тех, кто уже заходил на сайт.

**Анимации уважают системную настройку** `prefers-reduced-motion` и отключаются, если пользователь просил уменьшить движение.
